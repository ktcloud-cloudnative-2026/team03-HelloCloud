## 공통 확인 순서
1. 어느 서비스 · 환경인가 — 대시보드에서 에러율이 오른 서비스 확인
2. `kubectl get pods -n <네임스페이스>` — 상태 · 재시작 수
3. `kubectl describe pod <파드> -n <네임스페이스>` — Events
4. `kubectl logs <파드> -n <네임스페이스> --previous` — 직전에 죽은 컨테이너 로그
5. 최근 배포 확인 — Argo CD 이력, 최근 merge된 PR
