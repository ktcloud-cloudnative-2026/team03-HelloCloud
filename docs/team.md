## 완료 기준 (Definition of Done)
PR을 머지하기 전에 확인하는 기준을 팀이 정합니다. 예:
- [ ] 테스트 통과 (CI 초록)
- [ ] dev에 배포되어 동작 확인
- [ ] 관련 문서 수정 (API 명세 · 아키텍처 등)

## 회의
| 항목 | 정한 내용 |
|---|---|
| 스프린트 | 1주 단위 · 월요일 계획, 주말 전 데모 |
| 스크럼 | 매일 비동기 · 어제 한 것 / 오늘 할 것 / 막힌 것 |
| 회고 | <언제> · 다음에 바꿀 것을 이 문서에 기록 |
