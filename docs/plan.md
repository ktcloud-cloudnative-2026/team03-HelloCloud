## 1. 해결할 문제

팀은 대화, 할 일, 파일, 화상 회의에 서로 다른 도구를 써서, 도구마다 팀원을 초대하고 권한을 관리해야 하며 일과 관련된 내용도 여러 곳에 흩어지는 문제를 해결하고자 합니다.

## 2. 대상 사용자

인원이 유동적인 팀

| 사용자 | 하는 일 |
|---|---|
| 조직 소유자(OWNER) | 조직을 만들고 팀원을 초대함 |
| 조직 멤버(MEMBER) | 초대를 수락해 합류하고 협업 기능을 사용함 |

## 3. 핵심 시나리오

1. 가입과 로그인 → 조직 만들기 → 초대 링크로 팀원 합류
2. 카드 만들기 → 담당자와 기간 지정 → 끌어서 진행 상태 옮기기
3. 채널에서 대화 → 파일 공유 → 화상 회의
4. 회의실 예약 → 캘린더(일정관리) 자동 연동
5. 문서나 드로잉 공유 툴 활용

## 4. 범위

| 이번에 할 것 | 이번에 안 할 것 |
|---|---|
| 로그인, 조직, 초대, 접근 제한 | SSO(SAML) |
| 메신저 (문서 미리보기, 채팅to칸반 보드 이슈 생성, 결정 로그 채널, '확인 필요' 메세지) | 메시지 번역 |
| 파일 공유 | 외부 공개 링크 |
| 캘린더 (일정 관리), 팀 일정 + 각 개인 일정 | Google·Outlook 캘린더 연동 |
| 회의실 예약 | 회의실 현황 디스플레이·IoT 연동 |
| 근무시간에 맞춰 알림 예약 (지금 보내기 가능) | AI 기반 발송 시간 추천 |
| 칸반 보드, 간트 차트 | GitHub·Jira 연동 및 가져오기 |
| 화상 통화(+ VoicetoText (AI)) | 화상 통화 녹화 |
| 문서나 드로잉 공유 툴 | 템플릿 마켓 |

## 5. 성공 기준

| 기준 | 목표 | 확인 방법 |
|---|---|---|
| 조직 및 권한 관리 | 초대 한 번으로 합류, 탈퇴 시 5초 이내 권한 일괄 회수, 조직 간 접근 차단 | 초대·탈퇴 전후 권한 및 다른 조직 접근 차단 확인 |
| 메신저 채팅 전달 | 다른 파드의 사용자에게 1초 안에 전달 | 메시지 100건 전송 후 시각 비교 |
| 회의실·캘린더 연동 (팀 일정과 개인 일정나누기.) | 예약·변경·취소 3초이내 자동 반영 및 중복 예약 방지, 팀 일정은 조직 전체 공개·개인 일정은 본인만 접근 | 캘린더 반영 확인 및 동일 시간대 동시 예약 시 한 건만 성공하는지 중복 예약 0건 확인, 일정 간 공개 범위 확인 |
| 파일 공유 | 조직 내 파일 업로드·다운로드·삭제 및 문서 미리보기 지원 | 파일 공유·미리보기 동작, 다운로드 원본 일치 및 삭제 결과 확인 |
| 알림 예약 | 예약 시각과 즉시 보내기 선택 후 각각 5초 이내 발송 | 예약·즉시 발송 각 3회 실행 후 발송 시각 확인 |
| 칸반 보드 | 업무 카드 생성, 수정, 삭제, 이동 가능, 변경 사항 3초 이내 다른 사용자 화면에 반영 | 카드 생성, 이동 및 실시간 동기화 확인 |
| 화상 통화 | 최대 8명까지 10분동안 통화 지속 가능 | 실제 통화 |
| 문서 및 드로잉 생성 및 저장 | 멤버들이 문서나 드로잉을 생성 및 수정 가능 | 문서 및 드로잉 생성 및 수정 |
