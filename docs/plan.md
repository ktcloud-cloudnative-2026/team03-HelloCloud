## 프로젝트 목표

- 대화, 할 일, 파일, 화상 회의를 조직 하나로 묶은 협업 툴을 2027-01-03까지 만듭니다.
- 팀원 4명 모두가 서비스 개발부터 k8s 배포와 운영까지 직접 해 보며 전 과정을 익힙니다.

## 1. 해결할 문제

`[가정]` 팀은 대화, 할 일, 파일, 화상 회의에 서로 다른 도구를 써서, 도구마다 팀원을 초대하고 권한을 관리해야 하며 일과 관련된 내용도 여러 곳에 흩어집니다.

## 2. 대상 사용자

`[가정]` 인원이 유동적인 팀

| 사용자 | 하는 일 |
|---|---|
| 조직 소유자(OWNER) | 조직을 만들고 팀원을 초대함 |
| 조직 멤버(MEMBER) | 초대를 수락해 합류하고 협업 기능을 사용함 |

## 3. 핵심 시나리오

1. 가입과 로그인 → 조직 만들기 → 초대 링크로 팀원 합류
2. 카드 만들기 → 담당자와 기간 지정 → 끌어서 진행 상태 옮기기
3. 채널에서 대화 → 파일 공유 → 화상 회의

## 4. 범위

| 이번에 할 것 | 이번에 안 할 것 |
|---|---|
| 로그인, 조직, 초대, 접근 제한 | 멤버 제거, 조직 탈퇴, 문서 공동 편집, 알림, 검색 |
| 칸반, 간트(일정이 밀리면 먼저 제외) | 카드 댓글, 칸반 실시간 동기화 |
| 파일함, 채널 메신저 | 메시지 수정, 읽음 표시 |
| 화상 통화 | 회의 녹화 |

## 5. 성공 기준

`[제안]`

| 기준 | 목표 | 확인 방법 |
|---|---|---|
| 기능 완성 | 요구사항의 수용 기준 전부 통과(간트를 뺀 경우 그 항목 제외) | S8 데모 |
| 채팅 전달 | 다른 파드의 사용자에게 1초 안에 전달 | 메시지 100건 전송 후 시각 비교 |
| 화상 통화 | 4명이 10분 동안 끊김 없이 통화 | 실제 통화 |
| 배포와 롤백 | 배포 설정 머지 또는 revert 후 5분 안에 반영 | Argo CD `Synced` 시각 확인 |
| 장애 복구 | VM 재부팅 후 손 작업 없이 복구 | 노드와 앱 상태 확인 |
| 학습 | 4명 모두 인프라와 기능 개발을 1회 이상 담당 | GitHub Project 기록 |
