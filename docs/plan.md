## 1. 해결할 문제

팀은 대화와 파일 공유에 서로 다른 도구를 써서, 도구마다 팀원을 초대하고 권한을 관리해야 하며 일과 관련된 내용도 여러 곳에 흩어지는 문제를 해결하고자 합니다.

## 2. 대상 사용자

인원이 유동적인 팀

| 사용자 | 하는 일 |
|---|---|
| 조직 소유자(OWNER) | 조직을 만들고 팀원을 초대함 |
| 조직 멤버(MEMBER) | 초대를 수락해 합류하고 협업 기능을 사용함 |

## 3. 핵심 시나리오

1. 가입과 로그인 → 조직 만들기 → 초대 링크로 팀원 합류
2. 채널에서 대화 → 파일 공유 → 내려받지 않고 미리보기
3. 중요한 메시지를 결정 로그에 등록 → 꼭 봐야 할 사람에게 확인 요청

## 4. 범위

| 이번에 할 것 | 이번에 안 할 것 |
|---|---|
| 웹사이트 | 데스크톱 앱 · 모바일 앱 |
| 로그인, 조직, 초대, 접근 제한 | SSO(SAML) |
| 메신저 (문서 미리보기, 결정 로그 채널, '확인 필요' 메세지) | 메시지 번역 |
| 파일 공유 | 외부 공개 링크 |
| | 캘린더 · 회의실 예약, 알림 예약, 칸반 · 간트, 화상 통화, 문서 · 드로잉 공동 편집. 8주 안에 끝낼 수 있도록 2026-11-10에 범위에서 뺐습니다 |

## 5. 성공 기준

| 기준 | 목표 | 확인 방법 |
|---|---|---|
| 조직 및 권한 관리 | 초대 한 번으로 합류, 탈퇴 시 5초 이내 권한 일괄 회수, 조직 간 접근 차단 | 초대·탈퇴 전후 권한 및 다른 조직 접근 차단 확인 |
| 메신저 채팅 전달 | 다른 파드의 사용자에게 1초 안에 전달 | 메시지 100건 전송 후 시각 비교 |
| 파일 공유 | 조직 내 파일 업로드·다운로드·삭제 및 문서 미리보기 지원 | 파일 공유·미리보기 동작, 다운로드 원본 일치 및 삭제 결과 확인 |
